# 小焕1号 · XiaoHuan-1

给一个简牍上残缺的字，排出最可能是哪几个字。

**它不给答案，它给候选。**

---

## 能力

| 指标 | 数值 |
|---|---|
| Top-1 | **28.4%** |
| Top-5 | **35.2%** |
| 测试集 | 483 个字，561 个类 |
| 随机基线 | 0.18% |

划分方式为「按简留出」——同一枚简上的字只出现在训练集或测试集之一，防止背题。

当前水平是随机基线的 **158 倍**。

## 体积与速度

| | |
|---|---|
| 模型体积 | 4.8 MB |
| 单字推理 | 3 ms（CPU） |
| 需要 GPU | 不需要 |

## 和谁比过

| 模型 | Top-1 | Top-5 | 结果 |
|---|---:|---:|---|
| **小焕1号** | **28.4%** | **35.2%** | — |
| Qwen3-VL-Embedding-2B（零样本） | 8.5% | 18.3% | 小模型胜 3.3 倍 |
| Qwen 同一模型（LoRA 微调后） | 6.5% | 14.0% | 微调后更差 |
| ResNet18（ImageNet 预训练） | 3.3% | 7.0% | 输入尺寸不匹配 |

还试过级联重排（小焕1号出 Top-50，Qwen 重排），Top-1 从 20.0% 掉到 6.7%。

**三个融合方向全部失败**——这个任务上，专用小模型就是最优解。

原因不复杂：通用多模态模型学的是图文语义对齐，而「日」和「曰」、「木」和「禾」语义无关、字形极近，正好是它的盲区。

## 边界（这四条比上面的数字更重要）

- **只认识训练集里的字**。库外的字，它会给一个最像的答案，不会说「我不认识」。
- **残损越重越不准**。缺一半以上的字，基本靠猜。
- **输入必须是单个字图**。整页要先切分，切分错了它也认不对。
- **不能判断残缺程度**。试过九项指标，最高 AUC 0.646，接近随机。

### 用它的正确姿势

把它当一个**快速筛子**，不是**鉴定专家**。

它把两万字的搜索空间压到几十个候选，剩下的由人来判断——辞例、时代、语法位置，这些它都不懂。

如果前三个候选字形相近但意思不搭，说明它在看形状，这是对的；
如果意思相近而字形不像，说明它在猜语义，这种要警惕。

## 架构

```
输入  64×64 灰度字图
  ↓
4 层卷积块（每块：Conv-BN-ReLU ×2 + MaxPool）
  32 → 64 → 128 → 256
  ↓
全局平均池化
  ↓
256 维嵌入向量
```

训练方式是**对比学习**：同类字靠近，异类字远离。产出是向量，不是标签。

从零训练，未使用任何预训练权重。

## 训练数据

| 阶段 | 数据 | 规模 |
|---|---|---|
| 第一次学习 | DeepJiandu（西北师范大学 + 甘肃简牍博物馆，2025） | 300 类 / 17,837 样本 |
| 第二次学习 | 北京大学藏秦简牍图版 | 2,564 字 / 561 类 / 79 页 |

数据管线为自建：PDF 图版页 → 切简（列投影 + 旋转矩形双策略）→ 切字（行投影）→ 读释文（视觉模型）→ 顺序配对（difflib）。

**数据不可公开分发**（北京大学藏秦简牍，上海古籍出版社 2022）。

## 用法

```bash
python3 recognize.py 字图.png        # 单张
python3 recognize.py 整页.png --page # 整页，自动切字
```

输出：每个字的前 10 个候选，附余弦相似度。

## 关于「自研」

分三层说清楚：

| 层面 | 是否自研 |
|---|---|
| **架构** | ❌ 标准 CNN，没有结构创新 |
| **权重** | ✅ 从零训练，没用预训练权重 |
| **数据** | ✅ 2564 个字图是自建管线从 PDF 切出来的 |

准确的说法是**「一个从零训练的专用模型」**，不是「自研架构」。

真正难的不是模型，是**数据管线**——把一本 744 MB 的扫描书变成 2564 条带标签的训练数据，这件事没有现成方案。
